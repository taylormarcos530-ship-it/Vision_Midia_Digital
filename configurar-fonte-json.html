Configurar fonte JSON pública

Informe o endereço que fornece os dados. A Vision gera outra URL para a página visual que você poderá cadastrar como conteúdo online na TV.

Somente fontes HTTPS públicas, sem usuário, senha ou chave privada. O servidor precisa permitir consulta pelo navegador (CORS).

Três cartões informativos independentes

Configure três fontes JSON para comunicações gerais. Cada cartão usa seu próprio título e avisos. Nenhum conteúdo é enviado ao Master até você cadastrar a URL gerada.

Abrir painel em tela cheia

As fontes precisam permitir CORS e seguir o formato de exemplo abaixo. Use somente fontes públicas sem tokens ou dados sigilosos.

Formato de dados aceito

{
  "titulo": "Avisos da comunidade",
  "itens": ["Atendimento das 08h às 18h", "Evento de sábado"]
}

O painel rejeita dados fora desse formato e conserva o último conteúdo válido armazenado quando a rede falha.

Somente homologação. A prévia não salva configurações no Master nem altera playlists. Para testes, use uma conta/TV de bancada. Não coloque senhas na URL: a URL gerada é pública e contém a URL de origem.
