▦WINDOWS

Vision Player para Windows

No Windows, o Vision Player já pode ser usado e instalado como PWA pelo Chrome ou Microsoft Edge.

  1. Abra o Vision Player.
  2. No navegador, escolha “Instalar aplicativo”.
  3. Depois, abra-o como um programa normal do Windows.
Abrir Player para instalar Não existe um .exe separado nesta versão; o modo PWA é o instalador atual do Windows.
